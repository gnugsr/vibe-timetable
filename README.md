# 🥐 대학생 시간표 - Vibe Coding

구세린의 대학 시간표를 관리하는 웹 애플리케이션입니다.

## 📚 프로젝트 소개

코딩 초보자를 위해 만든 간단하고 예쁜 시간표 웹페이지입니다.
- **전공**: 기계융합공학과
- **기능**: 강의 추가, 수정, 삭제
- **저장**: 브라우저의 로컬스토리지에 자동 저장

## 🎨 특징

- 🥐 소금빵 테마의 따뜻한 색상
- 🖱️ 움직이는 소금빵 커서
- 📱 반응형 디자인 (모바일 지원)
- 📝 강의 정보 자동 저장
- 🎯 직관적인 UI/UX

## 🚀 실행 방법

1. `index.html` 파일을 브라우저에서 열어주세요
   - 더블 클릭 또는 우클릭 → "기본 프로그램으로 열기"

## 📋 사용 방법

### 강의 추가
1. 우측의 "강의 추가" 폼에서 다음 정보를 입력:
   - 요일 (월~금 선택)
   - 교시 (1~8교시 선택)
   - 강의명
   - 강의실
   - 수업시간

2. "강의 추가" 버튼 클릭

### 강의 삭제
- 시간표의 강의명을 클릭하면 상세 정보와 삭제 옵션이 표시됩니다

## 📂 파일 구조

```
바이브 코딩/
├── index.html      # HTML (페이지 구조)
├── style.css       # CSS (스타일링)
├── script.js       # JavaScript (기능 구현)
└── README.md       # 프로젝트 설명
```

## ⚙️ 기술 스택

- **언어**: HTML5, CSS3, JavaScript (ES6)
- **저장소**: 브라우저 LocalStorage
- **외부 라이브러리**: 없음 (순수 HTML/CSS/JS)

## 🛠️ 수정 포인트 Top 3

### 1️⃣ 색상 변경
`style.css`에서 다음 색상을 변경하면 전체 테마가 바뀝니다:
- `#D2691E` - 진한 초콜릿 갈색
- `#8B4513` - 어두운 갈색
- `#CD853F` - 밝은 갈색

### 2️⃣ 커서 이모지 변경
`index.html`에서 `<div class="custom-cursor">🥐</div>`의 이모지를 다른 것으로 변경 가능

### 3️⃣ 시간표 범위 확장
`script.js`에서 강의 시간대를 확장:
- 현재: 9시~17시 (8교시)
- 더 추가하려면 `index.html`의 `<tbody>` 내용 확대
